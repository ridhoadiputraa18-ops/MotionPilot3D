# Motion Pilot 3D — Kotlin starter

A minimal Android-native OpenGL ES 2.0 prototype using accelerometer and gyroscope input.

## Build APK using GitHub Actions
1. Upload this folder to a GitHub repository.
2. Push to the `main` branch, or open Actions and run **Build Motion Pilot 3D APK**.
3. Download the `MotionPilot3D-debug` artifact and install the APK.

Open the project in Android Studio for the conventional Android development workflow.

## Prototype status
This starter renders a simple low-poly aircraft and moving 3D obstacle blocks. It is not yet a finished realistic flight simulator. Collision detection, scoring, menus, detailed aircraft/terrain models, sound and polished lighting are planned next. Sensor axis mapping may need calibration for the phone's landscape orientation.
